IGNITE WEB CO — WEBSITE UPLOAD

1. Extract Ignite-Web-Omaha.zip.
2. Upload the extracted files and the photos folder to the publishing root of
   the ignitewebomaha/igniteweb GitHub Pages repository. Replace the existing
   files with the same names. index.html, studio.css, app.js, and CNAME should
   sit alongside the photos folder. Upload the hidden .nojekyll file too.
3. Commit the upload to the branch configured in Settings > Pages. After
   deployment finishes, open https://ignitewebomaha.com/ in a private window.

No build step is needed. CNAME preserves the ignitewebomaha.com domain.
The homepage and portfolio point to photos/ignite-web-co-share.jpg for link
previews. Apps that cached an older preview may take time to refresh it.

After upload, check the homepage, both portfolio screenshot buttons, the
Fire Alarm Field Pro website link, and verify receipt of a test inquiry.
